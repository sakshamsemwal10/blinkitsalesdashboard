# Blinkit Grocery Sales Dashboard | Power BI

An interactive **Power BI dashboard** built to analyze Blinkit grocery sales data and generate meaningful business insights through data visualization and analytics.

## 📊 Project Overview

This project focuses on analyzing grocery sales data across different product categories, fat-content levels, outlet types, outlet sizes, outlet locations, and establishment years.

The dashboard converts raw sales data into an interactive business intelligence report that makes it easier to identify sales trends, compare outlet performance, and understand customer and product patterns.

I developed this project while using a Power BI tutorial by **Data Tutorials** as a learning reference, with the goal of understanding the complete dashboard development workflow.

## 🎯 Objectives

- Analyze overall grocery sales performance
- Compare sales across different item types
- Analyze sales based on fat content
- Compare outlet performance by size and location
- Understand sales trends across outlet establishment years
- Analyze performance across different outlet types
- Create interactive KPIs and visualizations
- Practice Power Query, data modeling, and DAX
